# 连接校园网
这里提一嘴，新学生刚来的宿舍网口是不开通的，需要找人来开通，已经开通的可以无视此信息。
# 准备操作
当你连桌子底下那个网口时会弹出让你跳转浏览器进行网络认证，一定要记得收藏网页！！！不然以后用的时候忘了登录地址不好搞。
这里需要注意，第一次用电脑连接桌子下方的网口时，网络服务器会记住你的MAC地址，此时你如果注销登录用软路由连接的话是拿不到IP的，它不认这个MAC地址。需要等那边的端口老化， 我也没测出来老化时间，所以我建议等待一星期再进行折腾。等时间过去后你在两台设备随便登录校园网。
